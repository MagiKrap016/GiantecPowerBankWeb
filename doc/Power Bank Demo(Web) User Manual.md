## 简介

本项目主要在Web端实现新国标充电宝”碰一碰“读取电量等信息的功能；本项目仅作为演示工具，不代表最终to C成品。



## 1. 使用指南

### 1.1 如何使用

#### 1.1.1 安卓：通过 NFC 标签读取

1. **手机准备工作**：确保您的设备支持 NFC 功能，并且安装有 Chrome 内核版本较高的浏览器

2. **卡片准备工作**：写入两条Ndef消息

   消息 1 (目标网页Url): 

   https://magikrap016.github.io/GiantecPowerBankWeb/

   消息 2 充电宝状态信息(纯文本格式): 

   B1102200016810B80B10270410800C005005202DD80ECE0EA61D3019000019005F0050

3. **打开网页**：手机靠近卡片，自动打开目标网站

4. **读取数据**：等待网站加载完成后，手机再次靠近卡片，读取到充电宝数据

5. **查看信息**：应用会自动解析并显示充电宝的详细信息

#### 1.1.2 IOS/鸿蒙：通过 URL 参数加载

1. **手机准备工作**：确保您的设备支持 NFC 功能

2. **卡片准备工作**：写入一条Ndef消息

   消息  (目标网页Url+充电宝状态信息): 

   https://magikrap016.github.io/GiantecPowerBankWeb/?pwrbkdata=B1102200016810B80B10270410800C005005202DD80ECE0EA61D3019000019005F0050

3. **打开网页**：手机靠近卡片，自动打开目标网站

4. **读取数据**：等待网站加载完成后，自动解析并显示充电宝信息

#### 1.1.3 界面说明

- **电池电量环**：直观显示当前电量百分比
- **基本信息卡**：显示充电宝状态、电池容量、循环次数、健康状态
- **电池参数卡**：显示当前电压、电流、温度
- **更多信息卡**：显示充电阈值、放电阈值、最大/最小电压、最大/最小温度

### 1.2 其他说明

1. **网站说明**：目前网页项目部署在私人服务器上，后续可能会出现变动，请关注修订记录

   > [!WARNING]
   >
   > 非企业级服务器，请勿随意分享链接，导致服务器流量过载

2. **数据说明**：目前写入Ndef的为静态数据，仅为演示作用，实际应用需要下位机Mcu侧不断更新EE中数据，充电宝数据协议说明请参照对应说明文档

3. **IOS/鸿蒙**：由于系统权限问题无法使用Web NFC API，只能用URL参数加载方案

4. **浏览器兼容性**：对于Android系统，需要注意浏览器Chromium内核版本为89+，推荐Chrome或Edge
